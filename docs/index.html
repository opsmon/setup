После установки

Сделайте вручную

  • 1
    Откройте новое окно Terminal

    Так загрузятся новые настройки Zsh и PATH.

  • 2
    Запустите Docker Desktop

    Примите системные запросы и дождитесь запуска Docker Engine.

  • 3
    Откройте VS Code

    При необходимости войдите в аккаунт и включите Settings Sync.

  • 4
    Настройте Git identity

    Укажите собственные user.name и user.email.

Пять простых шагов

От коробки до работы.

Сначала прочитайте скрипт. Затем запустите и дождитесь понятного отчёта по каждому шагу.

  1. 1
    Откройте Terminal

    Подойдёт стандартный Terminal или iTerm2.

  2. 2
    Проверьте скрипт

    Посмотрите код до удалённого запуска.

  3. 3
    Запустите установку

    Одна команда запускает весь последовательный setup.

  4. 4
    Следите за логами

    Каждое действие явно отмечено в терминале.

  5. 5
    Перезапустите shell

    Откройте новое окно и начинайте работу.

Снимок системы

Сначала понять. Потом устанавливать.

Сборщик анализирует текущие пакеты, инструменты и безопасную часть конфигурации. Отчёт остаётся только на машине и не попадает в git.

Собрать отчёт ./scripts/collect-current-system.sh Результат system-report/

Создано для проверки

Безопасность видна в коде.

Backup before changes

Existing configs are saved under ~/.macos-setup-backup/.

Повторный запуск

Установленные компоненты пропускаются, одинаковые файлы не копируются.

Никаких секретов

SSH keys, credentials, history и environment не переносятся.

Defaults только по согласию

Системные настройки macOS являются отдельным opt-in шагом.
